# Decision implementation map

Architecture decision records own contracts and rationale. This map keeps
concrete source and documentation locations outside those records so a file move
does not rewrite an architectural decision. The referenced headers, guides, and
policy documents remain the owners of their implementation details; this map
adds no contract or alternative source of truth.

| Decision                                                | Current implementation or documentation owner                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ADR-0004 — threading boundary and native tick admission | [Server public contract](../../include/kith/server/server.h) defines callback registration, admission, lifetime, and drain behavior.                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ADR-0005 — bounded relevance budgets                    | [Performance budgets](performance_budgets.md) reconciles budgets with gates and the per-instance fidelity ceiling.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ADR-0007 — framework wire byte order                    | [Protocol public contract](../../include/kith/proto/proto.h) defines the frame header and correlation trailer. Application payload examples live in `examples/`. [Event schema](../event_schema.md) owns explicit correlation propagation into observability.                                                                                                                                                                                                                                                                                         |
| ADR-0008 — opaque handles and stable value types        | Private definitions live under `src/`; public contracts live under `include/`. The scatter/gather value-type analogy refers to the standard `struct iovec`; it does not require framework DTOs to share that type's layout.                                                                                                                                                                                                                                                                                                                           |
| ADR-0014 — deterministic simulation and cadence         | [Randomness public contract](../../include/kith/util/rng.h) owns the deterministic generator surface. [Tick-clock public contract](../../include/kith/util/tick_clock.h) defines integral and precise conversions; [server timing guide](../guides/server_timing.md) explains cadence and logical model time. [Floating-point build configuration](../../cmake/fpenv.cmake) disables contraction with `-ffp-contract=off` and selects SSE2 on 32-bit x86; [floating-point environment check](../../src/util/fpenv.c) verifies `FLT_EVAL_METHOD == 0`. |
| ADR-0017 — hardening and wheel distribution             | [Release guide](../guides/releases.md) owns wheel packaging, repair, and verification mechanics.                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ADR-0019 — observability                                | [Event schema](../event_schema.md) defines correlation carriers for logs, metrics, and control events.                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ADR-0020 — scaling certification                        | [Repository policy](../../AGENTS.md), section 4.4, owns gate thresholds, metric definitions, and harness profiles. [Scaling checklist](../guides/scaling_checklist.md) owns execution and interpretation; [topology documentation](topologies.md) explains the embedded and distributed split.                                                                                                                                                                                                                                                        |

Decision-level names such as io_uring, xoshiro256\*\*, representation preset
names, and observability counter names remain in the records where naming the
technology, algorithm, preset, or metric is part of the decision itself.
